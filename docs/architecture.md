# 架构与接口

本机单人应用：React + TypeScript + Vite，FastAPI，SQLite。只监听 loopback，不支持账户、多人共享、通用导入或直接公网部署。网页与本地 API 同源；写操作核对 Host、Origin，只有已注册资产可被读取。

## 数据边界

`content/question-pool/manifest.json` 是 schema v2 入口，登记 `pool.json` 与资产 SHA-256。题目有稳定 `id`、`canonical_id`、`part`、`group_id`、题干/选项及私有答案。材料组拥有完整题目列表、文本/图表；听力组保存独立音频和逐句字幕。发布题库没有原套题注册表、原 PDF、原页链接或可逆来源映射。

程序将题库稳定 ID 与每轮 1..N 的题号分开。阅读填空使用显式题目占位符重编号，不替换材料中的日期、价格或插句位置。共享材料不拆题。完整卷固定各 Part 的题量，Part 7 保留 10 组单篇共 29 题、2 组双篇与 3 组三篇共 25 题。

随机选择在精确题量及完整题组限制下，最大化偏好状态题数；等价组合随机抽取。偏好不足时补齐其余题目。听力严格模拟抽取音频不能超过 2700 秒，否则重抽或拒绝；不裁正式内容、不变速、不缩短正常答题间隔。

题库详情以分页卡片和只读模态框呈现。题干、共享文章及表格只从已核验文本生成可选取的 Markdown/表格内容；必要照片和图表保留原资产。原始 HTML 与主动远程内容不进入材料渲染路径。

## 作答与计时

每轮持久化不可变题目、答案、材料与音频边界快照。明确重练复制原快照和原顺序；新随机练习重新抽题。答案在事务中写入，校验作答轮、标签页所有权、截止时间、版本及幂等 mutation ID。交卷或到期只判一次，报告不随以后题库更正而就地改变。

计时以服务端单调时钟和截止时间为准。严格完整模拟为听力 2700 秒、阅读 4500 秒，合计 7200 秒；听力结束锁定该阶段答案。页面通过同步投影显示倒计时。媒体故障、重启等保留中断状态；暂停仅限练习。答案/统计切换、页面进入后台和活动记录都不延长考试预算，也不改变计时锚点。

前台活动记录与考试计时分账。当前认领标签页按题发送目标，前端每 5 秒串行发送心跳；服务端对每次收到的目标使用 15 秒租约。租约、认领、暂停、阶段切换或重启结束旧目标。后台、统计页和暂停视图发送空目标；网络异常或请求延迟可能使停留统计漏记或多记，租约上限不等于整段网络异常的总误差上限。考试计时不依赖这些观察值。

## 学习统计

题库状态按 canonical ID 去重，取最近有效、已结束的实际答案。仅标记、浏览、未答交卷和无效中断轮不覆盖实际作答。错题是已做子集；各比例以全部题库为分母。查看详情只读，不创建练习/生词证据；严格模拟进行时锁定完整题解。Part 1/2 的口述题干及选项文本在明确展开题解前隐藏。

生词证据须用户确认确实因该词答错。同一道题只计一次，默认 3 道不同题且至少 2 篇材料才自动成为必背。支持撤回、掌握周期、词义与听辨区分。

用时图表展示当前前台题目的累计停留和首次有效作答前的累计时长，并提供 Part 汇总。新记录为 `from_start`；旧练习开始记录后为 `partial`；没有可验证数据的旧记录为 `unavailable`，缺失点保留为空值而不补猜。共享材料阅读归当前显示题，`first_answer_ms` 是记录到的前台累计，不是网络无关的点击延迟。交卷时冻结活动摘要，复看不改变报告。

## 主要 API

| 接口 | 用途 |
| --- | --- |
| `GET /api/question-pool` | 题量、完整题组大小、固定组卷模板 |
| `GET /api/question-pool/status` | 总量、已做/未做/错题及全题库比例、题目状态列表 |
| `GET /api/question-pool/questions/{id}?include_solution=false` | 只读详情，显式选择才含题解 |
| `POST /api/attempts` | 新随机练习或冻结重练 |
| `GET /api/attempts/{id}` | 当前作答及截止时间同步，隐藏私有答案 |
| `POST /api/attempts/{id}/start` | 媒体准备好后开始 |
| `PUT /api/attempts/{id}/answers/{qid}` | 版本及幂等答案保存 |
| `PUT /api/attempts/{id}/activity` | 当前题目前台目标；认领会话+递增序号 |
| `POST /api/attempts/{id}/submit` | 幂等交卷并返回报告 |
| `GET /api/attempts/{id}/report` | 已结束的成绩及逐题复盘 |
| `GET /api/vocabulary` | 确认的词汇证据与必背状态 |
| `POST /api/backups` | 一致的学习数据备份，可含题库 |

创建示例：`{"scope":"part","mode":"practice","selection_preference":"wrong_first","random":{"part_counts":{"3":9}},"timer":{"kind":"countdown","duration_seconds":600}}`。新完整卷设置 `scope:full`；精确重练传 `retake_attempt_id`。状态与题解接口使用 `Cache-Control: no-store`。

## 验证与维护

后端测试注入可控时钟和临时数据库，覆盖跨阶段截止、冻结重练、随机组合、偏好、题库统计、并发保存、活动会话/租约及备份恢复。前端测试验证组卷参数、音频范围、字幕、状态筛选和答案/统计切换；实际浏览器验收覆盖它们在真实音频下的衔接。数据校验与安装/浏览器验收分别记录，不能相互替代。学习数据和准备证据始终在发行内容之外。
