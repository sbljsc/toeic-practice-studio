## 选项

##### 第 1 题

------- you are no doubt aware, the new security system requires the
installation of a backup power source in case an emergency situation arises.

- A. As
- B. For
- C. With
- D. So

## 答案 / 题解

##### 第 1 题

**答案：A**

------- you are no doubt aware, the new security system requires the
installation of a backup power source in case an emergency situation arises.
(A) As
 (B) For
(C) With (D) So
▶
正如您所知道的，新安全系统需要安装一个备用电源以防突发情况。
▶
解析
 分句you are no doubt aware是主系表结构，结构完整，横
线处应填入引导状语从句的从属连词。答案是 (A) as。
