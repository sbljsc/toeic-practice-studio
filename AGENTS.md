# TOEIC Practice Studio

Local single-learner application; never expose the service publicly.
Preserve question groups, immutable attempt snapshots, server deadlines, original audio speed and answer gaps.
No generic import feature in v1. Never commit .data, learner histories, backups or secrets.
Repository publication is authorized by the owner; keep learner data, source-preparation evidence and secrets out of every commit.
Third-party software and content retain their own rights; do not remove required license notices.
Run focused regressions, web typecheck/tests/build, API tests and tools/check_bundle.py for relevant changes.
