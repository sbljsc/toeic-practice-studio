# TOEIC Practice Studio

在本机浏览器运行的英语听力与阅读练习工具，无需账户。题库按单题、完整对话或完整文章组织；每轮重新抽题、编号，保留共享材料与独立作答记录。

当前仓库先保持**私有**，用于维护者检查。公开前需要维护者另行决定，并处理内容的再分发权限。个人学习、免费或禁止商用声明不代表取得第三方内容的授权。本项目提供受限的个人学习使用条款，**不是 OSI 开源许可证**，详见 [使用条款](LICENSE.md) 和 [内容权利说明](CONTENT-NOTICE.md)。

## 功能

- 2000 道题、1030 个完整题组，支持完整卷、仅听力、仅阅读、Part 1–7 专项及自定义各 Part 题数。
- 选题偏好：未做优先、错题优先、已做优先、全随机。优先项不足时从其余题目补齐；共享文章和对话始终整组抽取。
- 完整卷的题量为 Part 1–7 各 **6 / 25 / 39 / 30 / 30 / 16 / 54** 题。Part 7 保留单篇、双篇、三篇材料的结构。
- 工作区通过「答题／统计」切换；交卷默认显示统计，也可切回沿用答题布局的复盘，错误题号标红，解析、音频字幕和因果词汇编辑仍可使用。
- 鼠标选择答案、可复制文字、答题卡跳题、标记、刷新恢复；自动下一题可选并默认开启。标记按钮固定保留，不提供清空答案按钮。
- 「题库」以分页卡片显示已做、未做、错题的数量和占全部题库的百分比；点击卡片在可键盘操作的题目模态框中看只读详情，主动选择后才显示完整题解。
- 题干、共享文章和表格从核验文本显示为可选取的 Markdown 或表格，必要照片和图表继续保留；页面不执行原始 HTML 或主动加载远程内容。
- 交卷自动判题，显示正确、错误、未做和百分比，以及逐题解析、分 Part 表现。
- 用时曲线可按逐题或 Part 查看，并在明细中列出首次选答前的停留时间。旧记录没有数据时明确标为不可用；部分记录只从开始记录时计算，不补猜过去。
- 练习和交卷复盘支持单题/单篇重放、暂停、前后 10 秒、拖动进度；逐句英文字幕高亮、自动跟随和点击定位。中文对照默认隐藏。
- 生词通过你确认的错因累计；同一个词在多道错题中出现不会自动算作不认识。默认至少 3 道不同题、涉及至少 2 篇材料才列为必背，支持撤回和标记掌握。
- 学习数据保存在本机，支持备份和恢复。暂不支持通用文件导入。

## 安装与启动（Windows）

需要 **Python 3.12 或更新版本**、**Node.js 24 或更新版本**，并能使用随 Node.js 安装的 npm。首次安装需要联网下载依赖；日常练习不需要云服务。

1. 将仓库克隆或解压到本地可写目录。保持 `apps/`、`content/`、`Start.cmd` 等目录结构完整。
2. 双击 `Setup.cmd` 安装锁定的依赖并构建网页。若 Python 不在 PATH 中，可在命令行运行 `Setup.cmd "你的 Python 路径\python.exe"`。
3. 双击 `Start.cmd`，浏览器会打开 <http://127.0.0.1:8765>。保留启动窗口；结束时在该窗口按 `Ctrl+C`。

端口被占用时可运行 `Start.cmd --port 8766`；不自动打开浏览器可加 `--no-browser`。本服务只监听本机 `127.0.0.1`，不支持直接部署为多人公共网站。

首次启动的学习记录为空。题目位于 `content/question-pool/`；运行不依赖原始资料目录或维护者的磁盘路径。请不要把 `.data/`、`.env`、备份、个人答题数据库提交到仓库。

## 练习方式

在「练习」选择范围、选题偏好和模式，然后开始。完整卷和听读分区采用固定题量；专项可输入目标题数；自定义模式按 Part 分别输入题数，0 表示不选择。Part 3/4 必须是 3 的倍数，Part 6 必须是 4 的倍数；Part 7 由完整材料组合，无法凑足时会明确提示。

「答题」和「统计」切换不改变本轮题序、答案或阶段锁定。统计页是只读视图，不公开答案键或实时成绩；交卷后默认进入统计，切回「答题」即可复盘。自动下一题只改变作答后的导航，不会自动替用户选择答案，也不会绕过标记或提交。

练习倒计时预设为听力 **45 分钟**、阅读 **75 分钟**、完整 **120 分钟**，同一范围可保存自己的时长。严格模拟固定听力 45、阅读 75、完整 120 分钟；完整模拟听力结束后进入阅读，并锁定听力答案。模拟中禁止暂停、拖动音频、查看答案与字幕。

随机听力使用原速的完整正式题目片段，去掉原套题报号及与当前题目无关的片头、翻页和结束提示。保留正式内容、选项字母和正常答题间隔，不调语速。抽到的音频须不超过听力时段；超出时重新抽取或明确拒绝，绝不截断正式内容来凑时间。音频提前结束仍等到听力截止时间。它是随机练习模拟，不是官方原卷或官方分数测评。

## 题库状态与题解

「题库」以每道题的稳定身份去重，使用**最近一次有效、已结束且实际选了答案的作答**更新状态。正确后原来的错题退出「错题」；重复练习不会增加题库总量；未碰过的题、仅标记或未作答交卷不算已做。进行中的作答在本轮结束后计入。中断而无效的模拟不覆盖有效记录。

「已做」包含正确题和错题，因此 **已做 + 未做 = 2000**，错题是已做的子集，三项百分比均以全部题库为分母，并显示两位小数。筛选已做时同样包含错题。

题库按页显示题目卡片；点击卡片打开模态框查看题干、选项及共享材料，关闭后回到原来的页码和筛选。答案和解析默认隐藏。「显示完整解析」会展开答案、解释与对应听力材料；再次点击可隐藏。查看题解不会创建练习记录或生词证据。严格模拟进行中，完整题解暂时锁定。英文字幕优先显示，中文需单独点击。

## 计时、保存与恢复

服务端以截止时间和单调时钟计算时间，页面显示不会靠每秒减 1 计时。刷新、切后台或重播不会增加时间。练习可以暂停；严格模拟不能暂停。服务重启、音频中断等异常会记录状态，不会把不连续播放的模拟误算为完整模拟。

前台用时统计是独立的记录，不参与成绩判定。页面每 5 秒发送当前题目标注；切到后台、统计页或暂停时发送空目标。服务端对每次收到的目标使用 15 秒租约；网络异常或请求延迟时，逐题停留可能漏记或多记，不保证离线区间的统计精度。暂停不计入练习的作答总时长；考试时间仍由独立的服务端计时控制。

新练习从创建时覆盖全部前台记录。旧记录没有可验证历史时显示「不可用」；旧练习在升级后继续使用，最多只从开始记录的时刻显示「部分覆盖」。报告冻结交卷时已有的数据，复看和再次打开报告不会补写过去。首次有效作答前的累计时长是服务端记录的前台停留，不代表网络无关的点击延迟。

答案未确认保存时界面会提示，并在本机保留待提交草稿。截止后的草稿不会回写成绩或混入新一轮。同一轮由一个标签页写入，其他标签页可明确接管；遇到版本冲突需要选择保留的答案。

「设置」可备份学习数据，也可选择包含题库。恢复会先创建恢复前备份；正在计时的练习会阻止恢复。不要在服务运行时只复制 SQLite 主文件；请使用界面备份，并将重要副本另存。重做会创建新记录，不会删除历史。

## 数据与架构

```text
apps/web/              React + TypeScript 网页
apps/api/              FastAPI 模块化本地服务
content/question-pool/ 独立题目、材料、图片与听力片段
.data/                 本机答案、历史、生词与备份（不入库）
tests/api/             后端回归测试
tools/check_bundle.py  题库完整性与发布边界检查
```

后端使用 SQLite；组卷、不可变作答快照、判题、截止时间、媒体、词汇证据与备份分别管理。题库稳定 ID 与随机卷题号分离，冻结旧轮的答案及音频边界，避免以后更新题库改写历史。核心功能不需要 API Key。详细规则见 [架构与接口](docs/architecture.md)。

开发环境：

```powershell
npm ci
npm run web:check
npm run web:test
npm run web:build
.venv\Scripts\python.exe -m pip install pytest==8.4.2 httpx==0.28.1
.venv\Scripts\python.exe -m pytest tests/api -q
.venv\Scripts\python.exe tools/check_bundle.py
```

发行版的测试覆盖运行功能；依赖私有原资料和音频准备工具的四份准备测试保留在维护项目中，不进入发行版。少数原资料检查在缺少该资料时会明确跳过。题库准备环境、原资料对照表和个人验收数据库不随仓库分发。浏览器播放、安装与时间边界的实际验收范围见 [验收记录](docs/acceptance.md)；自动检查不等于人工听完所有录音或重新完整运行 120 分钟。
