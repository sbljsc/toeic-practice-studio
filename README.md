## 项目简介

TOEIC Practice Studio 面向本机、单人学习场景。题库以单题、完整对话或完整文章作为抽题单位，每轮重新选择和编号；同一材料下的多道题始终一起出现，保留材料与答案之间的对应关系。

程序通过本机服务与浏览器使用，学习数据写入本地 SQLite。核心练习功能无需模型 API Key，也不需要云端账户。当前提供 Windows 10/11 x64 便携包；包内包含运行时、锁定依赖、构建后的网页和同一份 2000 道题题库，使用者无需安装 Python 或 Node.js。源码运行仍是开发者的另一条入口。本服务仅监听 `127.0.0.1`，不提供公网多人服务。

## 快速开始

### 方式一：Windows x64 便携版（推荐）

1. 打开 [GitHub Releases v0.3.0](https://github.com/sbljsc/toeic-practice-studio/releases/tag/v0.3.0)，下载资产 `TOEIC-Practice-Studio-0.3.0-windows-x64.zip`。不要用 “Source code” 压缩包代替发行资产。
2. 将 ZIP **完整解压**到一个可写的普通文件夹，再进入固定的顶层目录 `TOEIC-Practice-Studio`。不要直接在压缩包预览窗口里运行，也不要只复制 `Start.cmd`。
3. 双击解压目录中的 `Start.cmd`。启动窗口会保持打开，默认浏览器应自动打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。
4. 使用期间保留启动窗口。结束时回到该窗口按 `Ctrl+C`；关闭启动窗口也会结束服务。

| 项目 | 便携版说明 |
| --- | --- |
| 系统 | Windows 10/11 x64；不需要管理员权限 |
| 运行时 | 内含固定版本的官方 CPython 3.14.8 嵌入式运行时、锁定并随包提供的 Python 依赖、已构建的 React 网页和完整题库 |
| 安装 | 不需要单独安装 Python、Node.js 或运行组件 |

| 学习数据 | 默认写入解压目录下的 `.data/`；该目录不包含在发行 ZIP 中 |

完整操作、备份升级与排障见[Windows 便携版指南](docs/windows.md)。

### 方式二：从源代码运行（开发者）

源码方式适合修改程序或参与开发。它需要 Python 3.12+、Node.js 24+（含 npm），首次建立环境时需要联网下载依赖；这些要求不适用于上面的便携包。

```powershell
git clone https://github.com/sbljsc/toeic-practice-studio.git
cd toeic-practice-studio
.\Setup.cmd
.\Start.cmd
```

不使用终端时，先双击 `Setup.cmd`，完成后双击 `Start.cmd`。首次安装会建立项目内的 Python 环境、安装锁定依赖并构建网页。

启动后浏览器打开 [本机练习页](http://127.0.0.1:8765)。保留启动窗口；结束时在该窗口按 `Ctrl+C`。

### 启动选项

```powershell
# 源码方式且 Python 不在 PATH 中：换成实际解释器路径
.\Setup.cmd "Python安装目录\python.exe"

# 默认端口被占用
.\Start.cmd --port 8766

```

首次启动的学习记录为空。发行包运行不依赖原始资料目录，也不需要维护者的磁盘路径。

## 使用指南

### 选择题目与模式

在「练习」选择范围、选题偏好和模式后开始。完整卷与听读分区采用固定题量：

| Part | 题型 | 完整卷题数 |
| --- | --- | ---: |
| 1 | 图片描述 | 6 |
| 2 | 应答问题 | 25 |
| 3 | 对话 | 39 |
| 4 | 独白 | 30 |
| 5 | 句子填空 | 30 |
| 6 | 篇章填空 | 16 |
| 7 | 阅读理解 | 54 |
| 合计 | 听力 100 题、阅读 100 题 | 200 |

Part 7 保留单篇、双篇、三篇材料结构。专项可输入目标题数；自定义模式逐 Part 设置，0 表示不选择。Part 3/4 题数须是 3 的倍数，Part 6 须是 4 的倍数；Part 7 按完整材料组合，不能凑足时会明确提示。

练习可重复开始，每轮有独立记录；新随机练习重新抽题，「按原题序精确重做」沿用原题序和快照。

### 计时与听力

| 范围 | 练习默认倒计时 | 严格模拟固定时长 |
| --- | ---: | ---: |
| 听力 | 45 分钟 | 45 分钟 |
| 阅读 | 75 分钟 | 75 分钟 |
| 完整 | 120 分钟 | 120 分钟 |

练习可保存自己的时长并暂停。严格完整模拟在听力结束后进入阅读，锁定听力答案；模拟中禁止暂停、拖动音频、查看答案与字幕。

随机听力使用原速的完整正式题目片段，移除原套题报号及与当前题目无关的片头、翻页和结束提示。保留正式内容、选项字母与正常答题间隔，不变速，也不截断题目来凑时间。所抽音频超过听力时段时重新抽取或明确拒绝；提前播放结束仍等到阶段截止。

刷新、切后台或重播不会增加考试预算。服务重启、媒体异常等会记录中断状态，不把不连续播放的模拟误算为完整模拟。

### 作答与交卷

选择答案后默认自动进入下一题，可关闭自动跳题；末题不会自动交卷。答题卡支持题号跳转与标记。

**同一篇文章的多道题排在同一页**：材料只显示一次，组内各题依次排在下方，每题独立作答与标记；「上一题／下一题」按题组翻页，答题卡点组内任意题会滚动到对应位置。听力题共用同一段录音，组内跳题时录音继续播放，跳到别的题组时录音停止。

工作区顶部的「答题／统计」切换不改变题序、答案和计时阶段。交卷前的统计视图隐藏答案键和实时成绩；交卷后自动进入统计，可查看成绩、逐题或分 Part 用时，再切回「答题」复盘。复盘选项只读，答题卡错误题号标红，仍可编辑错因和生词证据。

用时统计来自服务端收到的前台题目标注，可能受网络延迟或离线影响。每次目标采用 15 秒租约，这不代表累计误差上限。页面暂停、切到后台或统计页时会发送空目标；旧记录不补猜过去，显示「部分覆盖」或「不可用」。考试截止时间独立于这些观察数据。

### 题库状态与生词

「题库」按稳定题目身份去重，取最近一次**有效、已结束且实际选了答案**的作答更新状态。未答交卷、仅标记或浏览不计为已做；中断而无效的模拟不覆盖有效记录。

**已做 + 未做 = 2000；错题是已做的子集。** 三项百分比均以全部题库为分母，显示两位小数。正确重做后，原错题退出错题集合。

点击分页网格中的题号可看只读详情，关闭后保留页码和筛选。题解默认隐藏，需点击「显示完整解析」；浏览题目不会新增作答或词汇证据。严格模拟期间完整题解锁定。

只有你确认「确实因这个词答错」，该词才累计错因。默认至少涉及 3 道不同错题、2 篇不同材料后列为必背；同一词在多道错题中出现本身不会触发，支持撤回证据和标记掌握。

### 文本与历史题号

题库以**明文 Markdown** 保存：一个题组一个文件，文件里分「原文」「选项」「答案 / 题解」三章，题目编号、答案、题解与录音字幕都能直接阅读和手工编辑。文件的结构标记用较深的标题级别，材料自身的标题保持原有层级，两者不会混淆。完整格式见 [Markdown 题库格式](docs/md-question-store.md)。

题目序号和材料主标题采用 Markdown 三级标题，小标题采用四级标题，中文译文按原稿保留相应层级。正文段落自然衔接并留白；地址、邮件字段、对话、表格保留必要结构，词汇注释按词条与释义成组分段。必要照片和图表继续保留。

题干、选项、材料、字幕、译文、解析和词汇说明使用安全的 Markdown 显示规则。页面不执行原始 HTML，也不主动加载材料中的远程内容；选项与逐句字幕仅使用行内格式。

题库查找序号与每轮练习题号分开。Part 6 的填空通过稳定题目身份绑定到当轮题号。旧记录的题序、答案与成绩继续冻结；显示修复须完整源文本及编号关系匹配，不按旧题号猜测归属。为兼容较早快照，保留已转换为文本的注册题图资产。

本轮全库核对覆盖 2000 道题的 16,830 个非空文本字段，结合原稿疑点复核和实际页面验收；范围、结果与限制见[验收记录](docs/acceptance.md)。

## 数据与备份

学习答案、历史、生词和备份保存在程序目录的 `.data/` 中；便携版使用解压目录下的 `.data/`，发行 ZIP 不包含该目录。题库随 `content/question-pool/` 分发。请自行保管备份，不要向仓库提交 `.data/`、`.env`、个人数据库或备份文件。

- 在「设置」创建学习数据备份，也可选择包含题库。
- 恢复前会创建恢复前备份；正在计时的练习会阻止恢复。
- 服务运行时不要只复制 SQLite 主文件；请使用界面备份。
- 升级便携版前先通过界面创建备份，再按 `Ctrl+C` 停止服务；解压新版本时不得覆盖或删除原有 `.data/`。若换到新目录，启动新版后通过界面恢复备份。
- 源码更新前同样先备份并停止服务；更新代码后重新运行 `Setup.cmd` 和 `Start.cmd`。

答案未确认保存时界面会提示，并保留本机待提交草稿。截止后的草稿不会回写成绩或混入新一轮。同一轮由一个标签页写入，版本冲突需明确选择保留的答案。

## 常见问题与限制

| 问题 | 说明 |
| --- | --- |
| 便携版提示缺少 Python、Node.js、环境或网页构建 | 便携包已包含运行所需的组装内容；该提示通常表示使用了源码 ZIP、没有完整解压或文件不完整，并不是要求另装运行时。不要为消除此提示安装 Python 或 Node.js；重新下载 Release 中的 `TOEIC-Practice-Studio-0.3.0-windows-x64.zip`，完整解压后双击 `Start.cmd` |
| 源码方式提示缺少环境或网页构建 | 检查 Python 3.12+ / Node.js 24+，运行 `Setup.cmd`；详细错误见启动窗口 |
| 默认端口被占用 | 使用 `Start.cmd --port 8766` |
| 浏览器没有自动打开 | 保留启动窗口，先查看其中是否已显示监听地址，再手动打开 `http://127.0.0.1:8765` |
| 为什么错题百分比与已做不同 | 错题是已做子集，比例统一除以全部题库总量 |
| 为什么旧报告没有用时曲线 | 旧记录没有可验证的历史观察值，程序不补算过去 |
| 为什么音频长度未填满 45 分钟 | 完整题目片段按原速播放，模拟阶段仍按固定截止时间结束 |
| 能导入 PDF、Word 等题目吗 | 初版暂不提供通用文件导入 |
| 能部署为公共网站或多人同步吗 | 当前是本机单人应用，不提供账户、云同步或公网多人服务 |
| 成绩能换算官方分数吗 | 当前只提供练习统计，不提供官方计分或分数换算 |

Windows 便携包以 Windows 10/11 x64 为范围，实际 Release 资产仍需发布流程完成核验；安装验收使用维护者现有 Windows 主机，并在 `PATH` 中没有 Python / Node.js 的条件下模拟便携使用，不等同于全新 Windows 虚拟机验收。没有提供签名的自定义安装器，也不保证所有机器上的 SmartScreen 提示表现一致。自动检查不等于人工听完全部音频或重新完整运行 120 分钟。

题库位于 `content/question-pool/parts/part-N/`，每个题组一个 `.md` 文件，听力组另带同名 `.srt` 字幕；`assets/` 是共享图片池，`audio/` 是共享录音池。`tools/build_md_pool.py` 可从 `pool.json` 重新生成这棵 Markdown 树，`tools/group_transfer.py` 按题组导出与导入，导入时按「组 ID + 题 ID」重新分配编号以避免冲突。
